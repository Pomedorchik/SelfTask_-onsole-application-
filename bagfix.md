# BUGFIX - Исправление ошибок Task Manager

## Версия 0.0.9

### 1. Исправление отображения задач
**Проблема:** при просмотре задачи отображалось только её название, без описания.

**Решение:** изменена функция `show_collection()`. Теперь она позволяет посмотреть название и описание задачи.

### 2. Проверка номера задачи
**Проблема:** при вводе неправильного номера задачи программа могла завершиться с ошибкой.

**Решение:** добавлена проверка введённого номера и обработка ошибки `ValueError`.

### 3. Исправление редактирования
**Проблема:** редактирование изменяло только название задачи.

**Решение:** добавлена возможность изменять как название, так и описание задачи.

## Версия 0.1.0

### 4. Исправление подтверждения действий
**Проблема:** функция `check_confirm()` неправильно обрабатывала ответы пользователя из-за некорректного использования `or`.

**Решение:** исправлена проверка ответов. Теперь подтверждение и отмена работают правильно.

### 5. Исправление загрузки сохранений
**Проблема:** при отсутствии файла `saves.txt` программа могла завершиться с ошибкой.

**Решение:** добавлена обработка `FileNotFoundError`.

### 6. Улучшение сохранения данных
**Проблема:** закрытие файлов выполнялось вручную внутри `with open()`.

**Решение:** удалены лишние вызовы `close()`, так как конструкция `with` закрывает файлы автоматически.

### 7. Исправление удаления задач
**Проблема:** удаление задачи не всегда корректно учитывало подтверждение пользователя.

**Решение:** исправлена логика подтверждения перед удалением.
