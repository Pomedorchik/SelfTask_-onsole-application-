# BACKLOG - История разработки Task Manager

## Версия 0.0.1
Создан основной цикл приложения. Реализована начальная структура консольного менеджера задач.

## Версия 0.0.2
Добавлен ввод данных пользователя для создания задач.

## Версия 0.0.3
Основная логика разделена на отдельные функции. Начато функциональное разделение кода.

## Версия 0.0.4
Добавлены проверки пользовательского ввода и подтверждение действий.

## Версия 0.0.5
Реализовано сохранение задач в текстовый файл и загрузка данных при запуске.

## Версия 0.0.6
Добавлены функции создания, редактирования и удаления задач.

## Версия 0.0.7
Основной цикл приложения перенесён в отдельную функцию `main()`.

## Версия 0.0.8
Добавлена возможность сохранять название и описание задачи.

## Версия 0.0.9
Улучшено отображение коллекции задач. Добавлен просмотр описания выбранной задачи.

## Версия 0.1.0
Проведено ревью кода. Исправлены ошибки обработки пользовательского ввода, подтверждения действий и загрузки сохранений. Улучшена структура проекта.
